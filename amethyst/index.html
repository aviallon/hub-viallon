Amethyst Mod Manager

Personal Flatpak build of Amethyst Mod Manager.

This build carries the fix for the profile-conversion clone bug: converting a profile to profile-specific mods cloned a mod that contained a Wine prefix, whose dosdevices/z: points at /. Because the clone followed symlinks it copied the entire host filesystem; and once that was fixed, the directory-xattr copy aborted the conversion on bcachefs with ENOTEMPTY.

Install

flatpak remote-add --user --no-gpg-verify amethyst-aviallon \
  https://aviallon.github.io/hub-viallon/amethyst/repo/
flatpak install --user amethyst-aviallon io.github.Amethyst.ModManager

Or download amethyst.flatpakrepo and open it with your software centre.

Notes

  • This repository is unsigned, hence --no-gpg-verify. It is a personal build, not Flathub.
  • If you already have Amethyst from another remote, uninstall it first without --delete-data, so your settings and game instances survive, then install from this remote.
  • Branch: stable. Update with flatpak update. If the app is masked, flatpak mask --remove io.github.Amethyst.ModManager first, or updates will never arrive — even from here.

Repository files

  • repo/summary — Flatpak's repository index
  • repo/config — OSTree repository configuration
  • repo/refs/…/stable — the published commit
